ПОДКЛЮЧЕНИЕ К БЭКЕНДУ
URL бэкенда (Render.com)
Вставьте URL вашего сервиса с Render.com
Инструкция
1. GitHub → загрузить app.py и requirements.txt
2. Render.com → New Web Service → подключить репо
3. Build: pip install -r requirements.txt
4. Start: uvicorn app:app --host 0.0.0.0 --port $PORT
5. Environment: SPREADSHEET_ID + GOOGLE_TOKEN_JSON
6. Скопировать URL → вставить выше → Проверить
